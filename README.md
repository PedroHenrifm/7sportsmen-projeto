# 7 Sportsmen

## Descrição

O 7 Sportsmen é um site desenvolvido como parte de um projeto acadêmico, com foco na *ODS 3 - Saúde e Bem-Estar*. O objetivo do projeto é incentivar a prática de exercícios físicos e promover um estilo de vida saudável, utilizando uma plataforma simples e acessível para o público em geral.

> *OBS:* Este projeto foi desenvolvido como parte de um trabalho acadêmico, com o objetivo de aplicar metodologias ágeis no processo de criação. O foco principal foi a utilização de práticas ágeis para o desenvolvimento e entrega do projeto, de forma colaborativa e iterativa. Portanto, o que está apresentado aqui reflete o resultado final após a conclusão das sprints e entregas definidas ao longo do processo.

## Tecnologias Utilizadas

- *HTML5* - Estrutura e conteúdo do site  
- *CSS3* - Estilo e layout responsivo  
- *JavaScript* - Funcionalidades interativas  
- *PHP* - Backend  
- *GitHub Pages* - Hospedagem do site
